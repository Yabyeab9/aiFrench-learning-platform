# AI French Learning Platform 🇫🇷🤖

An AI-powered French learning platform built to help learners practice and improve their French skills through interactive exercises and smart feedback.

This project is also a personal learning journey combining **Java Spring Boot**, **security**, and **modern web technologies**.

---

## ✨ Features (Current)

- User registration (signup)
- User login (authentication)
- Secure password hashing with BCrypt
- JWT-based authentication
- Spring Security configuration
- PostgreSQL database integration
- Simple Login & Register UI pages

---

## 🛠️ Tech Stack

### Backend
- Java 17
- Spring Boot 3
- Spring Security
- JWT (JSON Web Tokens)
- PostgreSQL
- Maven

### Frontend (current)
- HTML
- CSS
- JavaScript (basic)

*(Planned: React / Next.js + TypeScript)*
